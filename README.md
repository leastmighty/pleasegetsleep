# 제잠자 (pleasegetsleep)

자고 싶은 시간을 알람처럼 정해두면, 그 시간 전부터 그리고 그 시간을 넘겨서까지
점점 세지는 잔소리 알림으로 눕게 도와주는 안드로이드 앱.

이 저장소는 **개인정보처리방침 페이지를 GitHub Pages로 서비스**한다.

- 개인정보처리방침: https://leastmighty.github.io/pleasegetsleep/privacy.html
- 소개: https://leastmighty.github.io/pleasegetsleep/

## 설정

Settings → Pages → Source: `main` 브랜치의 `/docs` 폴더.

**이 URL은 Google Play 스토어 등록정보에 제출된 주소다.** 앱이 게시돼 있는 동안
계속 살아 있어야 하므로 저장소 이름·Pages 설정·파일 경로를 바꾸지 말 것.
